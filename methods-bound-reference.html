1

Functions, relations and graphs

Functions

1.1 Notation, domain, range

A function is written f : D → R, f (x) = … — the domain is part of the definition, and changing it changes the function. The implied (maximal) domain is every x for which the rule returns a real number.

Rule containsRestriction
g (x)g (x) ≥ 0
loge(g (x))g (x) > 0 — strictly
1g (x)g (x) ≠ 0
tan(g (x))g (x) ≠ π2 + kπ

How it's asked: "State the maximal domain", or the domain is given and you must produce the range — which needs the shape of the graph, not just the rule. Also asked in reverse: a range is given and you find the domain that produces it.

Trap — working backwards through a reciprocal

Given f (x) = 4x + 2 with range (−2, 1], the domain is [−4, −1). Two things bite: the whole domain is negative, and multiplying an inequality by that negative x reverses it — which is also what swaps the open and closed ends over.

Trap — the limit is the asymptote

For g (x) = 2x + 5, limx→−∞ g (x) = 5: the exponential decays to zero, never below it, so the horizontal asymptote is y = 5 and the range is (5, ∞) — open, not closed.

1.3 Transformations

Write the image rule as y = A f (n(x − h)) + k. Read each parameter off separately:

ParameterEffectOn a point (x, y)
Adilation factor |A| from the x-axis (vertical); A < 0 reflects in the x-axisy → Ay
ndilation factor 1|n| from the y-axis (horizontal); n < 0 reflects in the y-axisx → xn
htranslation h in the +x directionx → x + h
ktranslation k in the +y directiony → y + k

Order. Dilations and reflections first, translations last. If a question gives a sequence, apply it exactly in the order stated — a different order generally gives a different image.

Method — image of a single point

Do not transform the rule. Carry the coordinates through one step at a time. (2, loge(3)) under "dilation 12 from the x-axis, then translate 3 right" → halve y, then add 3 to x → (2 + 3, 12loge(3)). Leave surds exact.

How it's asked: most often as "which sequence does not produce g", or "the graph of y = f (x) passes through (1, 3); y = 1 − g (2x − 3) must pass through …". For the second kind, set the inside equal to the known input, then apply the outer operations to the known output.

Trap — "from the axis" names the axis it moves away from

A dilation "from the x-axis" changes y. A dilation "from the y-axis" changes x. Also: a factor of 12 from the y-axis replaces x by 2x, not x2.

1.4 Finding a rule from a graph

  • Take asymptotes first — each one fixes a parameter outright and costs no algebra.
  • Substitute the intercepts to get simultaneous equations in what remains.
  • Solve, then check both intercepts against the finished rule.

For y = mx + a + c with vertical asymptote x = −6: the denominator vanishes there, so a = 6 — note the sign. The horizontal asymptote is y = c, which is a free check rather than a fourth unknown.

1.5 Composite functions

(f ∘ g)(x) = f (g (x)) exists ⇔ ran(g) ⊆ dom(f )

The domain of the composite is dom(g). To show a composite is defined, state both sets and the containment explicitly — that is what earns the mark.

How it's asked: "Show that g ∘ h is defined for all x ∈ R", then "find the range of g ∘ h". Also as a graph question: given the graphs of f and g, which could be g ∘ f?

Method — shape of a composite from two graphs

The outer function fixes the shape. Composing with a decreasing straight line reflects and rescales horizontally but cannot change the number of turning points or the direction of the ends. That eliminates half the options before you look at any detail.

1.6 Inverse functions

An inverse exists ⇔ f is one-to-one. Then:

dom(f −1) = ran(f )  ·  ran(f −1) = dom(f )
  • To find the rule: swap x and y, then make y the subject. Use the original domain to choose the correct branch of a ±.
  • The graphs are reflections in y = x; they meet on that line for increasing functions, but a decreasing function can meet its inverse off the line.
  • "Largest domain (−∞, a] on which an inverse exists" ⇒ a is the x of the turning point.

How it's asked: "Determine the equation and domain of f −1", or "find the largest a such that g restricted to (−∞, a] has an inverse" — for g (x) = e2x − 8ex + 7 that is a = loge(4).

Trap — a set of points has two hurdles

To have an inverse a set must first be a function (no repeated x) and then be one-to-one (no repeated y). Option sets routinely include relations that fail the first test, which most students never check.

1.7 Sums, products, and piecewise functions

dom(f + g) = dom(f ) ∩ dom(g) — the intersection, and an endpoint survives only if it is closed in both. For [−2, 3) and (−1, 5] the sum has domain (−1, 3), open at both ends.

A piecewise function is continuous at a join if the two rules agree there; it is smooth (differentiable) if the two derivatives also agree. Continuity does not imply smoothness — that gap is a standard extended-response part.

2.3 Solving exponential and log equations

  • Hidden quadratic. e2x − 8ex + 7 = 0 → let u = ex: (u − 1)(u − 7) = 0, so x = 0 or loge7. Discard any u ≤ 0 — ex is strictly positive.
  • Compress, then equate. 2log3(x − 4) + log3(x) = 2 → (x − 4)2x = 9. Solve, then reject roots failing x > 4.
  • Take logs of both sides when the unknown is an exponent with an awkward base.
Trap — always check the domain last

Log equations routinely produce an algebraically valid root that makes an argument zero or negative. Rejecting it, with the reason stated, is usually a mark in itself.

2.4 Polynomials

Remainder theorem: P (x) divided by (x − a) leaves remainder P (a). Factor theorem: (x − a) is a factor ⇔ P (a) = 0.

Matching coefficients beats long division whenever the target form is handed to you. To write x3 − x2 − 16x − 20 as (x + d)2(x − 5): the constant gives −5d2 = −20, so d = ±2; the x2 coefficient then picks d = 2.

Trap — one coefficient is not enough

Stopping at d2 = 4 and offering both values is an incomplete answer. A second coefficient is what fixes the sign.

Repeated factors and shape. A factor to an even power touches the axis; to an odd power ≥ 3 it crosses with a stationary point of inflection. For (x + 2)3(x − 5), the solution of y ≥ 0 is x ≤ −2 or x ≥ 5.

2.5 Simultaneous linear equations — the case split

This appears in some form in almost every paper. For

a1x + b1y = c1  and  a2x + b2y = c2

the determinant is Δ = a1b2 − a2b1.

ConditionGeometrySolutions
Δ ≠ 0lines cross onceunique
Δ = 0, equations are multiplessame lineinfinitely many
Δ = 0, not multiplesparallel, distinctnone
Method — never stop at the determinant

Setting Δ = 0 gives you candidate values, usually two. You must then substitute each one back and decide which gives no solutions and which gives infinitely many. The question always asks for one or the other, and the two roots split between them.

How it's asked: for ax + (2 − a)y = 3 with x + ay = 2a + 12, both a = −2 and a = 1 kill the determinant — but a = 1 gives parallel distinct lines (no solutions) and only a = −2 collapses them onto the same line. Naming the wrong root is the single most common way to lose all three marks.

2.6 Discriminant conditions

Δ = b2 − 4ac  ·  Δ > 0 two roots  ·  Δ = 0 one (repeated)  ·  Δ < 0 none

"f (x) > 0 for all x" with a positive leading coefficient means the parabola never touches the axis, so Δ < 0 — strictly. Using Δ ≤ 0 admits the tangent case, where f (x) = 0 somewhere, and that is precisely the distractor.

For roots of opposite sign in x2 + bx + c, note the product of roots is c: one positive and one negative needs c < 0. Sum of roots = −b, product = c is worth remembering — it turns several questions into one line.

3.2 Symmetry and identities

sin2θ + cos2θ = 1  ·  tan θ = sin θcos θ

Trap — which function flips sign

sin is odd, so f (0) = 2 sin(0 − π6) = −1, not +1. cos is even and would not change sign. Knowing which is which is worth more marks across a paper than any single result.

3.3 Graphs of y = a sin(n(x − h)) + k

Trap — three at once

For f (x) = −12 sin(3x + 2π): the amplitude is 12 (the minus reflects but does not make it negative), the period is 2π3 not π3, and the + 2π is a whole period so it changes nothing at all.

How it's asked: "a function with range [6, 12] is…" — read it as midpoint ± amplitude: k = 9, |a| = 3. The value of n is irrelevant to range, which is exactly what the distractors play on.

3.4 Solving over a domain

  • Isolate the circular function.
  • Transform the domain — substitute the endpoints of x's domain into the whole argument. This is the step that is skipped, and it is where the marks are.
  • Find the reference angle from the positive value, then use CAST for the quadrants.
  • List every solution for the argument inside its new domain, adding 2πk until you leave it.
  • Solve back to x, and check each lands in the original domain.

Predict the count first: an argument domain of width 4π is two full cycles, so expect four solutions of cos(2x) = −12 on [0, 2π] — namely π3, 2π3, 4π3, 5π3.

General solutions

sin θ = a ⇒ θ = 2kπ + sin−1a or (2k + 1)π − sin−1a
cos θ = a ⇒ θ = 2kπ ± cos−1a
tan θ = a ⇒ θ = kπ + tan−1a

A "subset of the general solution" question is checking whether the starting angle differs from a genuine solution by a whole multiple of the period — a family stepping by 2π can still be a subset of one stepping by π.

Trap — the inside derivative

Rewriting a surd as a power first makes chain-rule questions automatic. For 6x + 1 + 5 the constant vanishes and the 6 halves to 3, giving 3x + 1. Forgetting to multiply by the derivative of the inside is the classic slip.

4.3 Tangents, normals and gradients

tangent at (a, f (a)):   y − f (a) = f ′(a)(x − a)  ·  normal gradient = −1f ′(a)
  • Tangent with a given gradient: set f ′(x) = m and solve for the point(s) first.
  • Tangent through an external point: write the tangent at a general x = a, force it through the point, solve for a.
  • Common tangent to two curves: equal gradients and equal y at the point of contact. Two congruent upward parabolas with vertices at the same height share the horizontal tangent through both vertices — gradient 0.

4.4 Stationary points and their nature

Solve f ′(x) = 0. A quotient is zero only when its numerator is — and if the denominator is an exponential it never vanishes, so it can never contribute a solution or change the sign.

Sign of f ′ around x = aNature
− 0 +local minimum
+ 0 −local maximum
+ 0 +  or  − 0 −stationary point of inflection

A sign table earns the mark; an unsupported assertion earns nothing. Points of inflection generally are where f ″ changes sign — they need not be stationary.

Method — substitute the exponential, not the log

If f ′ = 0 gives ex = 4, find the y-value by substituting ex = 4 (so e2x = 16) rather than x = loge4. One line instead of five.

4.5 Increasing, decreasing and inequalities in f ′

f is strictly increasing where f ′ > 0, strictly decreasing where f ′ < 0. Give answers as closed intervals where the endpoint is included in the domain.

How it's asked: a product such as (x2 − x − 2) f ′(x) > 0, given only the location of the turning points. Factorise the quadratic, read the sign of f ′ off the shape of f, and multiply the signs region by region across the values that split the line.

4.6 Differentiability of piecewise functions

At a join x = c, h is

  • continuous if the two rules give the same value at c;
  • differentiable (smooth) if additionally the two derivatives agree at c.

To verify non-differentiability, compute both one-sided derivatives and show they differ — quoting two different numbers is the whole answer.

4.7 Rates of change

average rate over [a, b] = f (b) − f (a)b − a  (gradient of the chord)

Instantaneous rate is f ′ at the point (gradient of the tangent). Read the units off the context: metres per minute, dollars per day.

Trap — rank by the quotient, not the rise

Choosing the interval with the greatest average rate of change is not choosing the biggest climb. A longer interval with a larger rise can still lose to a shorter, steeper one — and can also win. Divide every time.

4.8 Optimisation

  • Write the quantity to be optimised as a function of one variable, using the constraint to eliminate the other.
  • State the domain — the physical restriction is usually where a mark sits.
  • Differentiate, solve = 0, and justify the nature.
  • Check the endpoints too: on a closed interval the extreme value may be there.

If the quantity is a square root, maximise the expression inside it — the square root is increasing, so the maximiser is the same and the algebra is far shorter. For A(k) = 12k2 − k3 on 0 < k < 12, differentiating 12k2 − k3 gives k = 8.

4.9 Newton's method

xn+1 = xn − f (xn)f ′(xn)
  • Keep full precision between iterations and round only the final answer. Rounding x1 first visibly changes x2.
  • The method fails or diverges where f ′(xn) = 0, or where the tangent throws the estimate far from the root.
  • An algebraic version is common: with f (x) = e−x − 2 and x0 = a, one iteration gives x1 = 1 + a − 2ea.

5.2 The n = −1 case

A reciprocal of a linear expression antidifferentiates to a logarithm. The index rule cannot be used: raising −1 by one gives 0 and a division by zero.

∫ 12x + 3 dx = 12 loge|2x + 3| + c

The modulus can be dropped when the domain forces the argument positive — e.g. x > −32.

Finding c

A boundary condition pins it down. With g ′(x) = 12x + 3 and g (1) = 0: g (x) = 12 loge(2x + 35), combining the two logs with the subtraction law.

5.3 Properties of the definite integral

∫ab f = −∫ba f  ·  ∫ab f = ∫ac f + ∫cb f  ·  ∫aa f = 0
∫ (p f + q g) = p ∫ f + q ∫ g  (linearity)

How it's asked: given ∫310 f = C and ∫710 f = D, find ∫73 f. Split at 7 to build the interval you have, then reverse the limits and change the sign: the answer is D − C. Forgetting the reversal gives C − D, which is always an option.

Method — extending the limit and getting less

If ∫12 f > ∫13 f, then ∫23 f < 0 — the added strip contributed negative signed area. Everything outside [2, 3] is irrelevant.

5.4 Signed area, total area, area between curves

  • Signed area is what the integral gives; regions below the axis count negative.
  • Total area requires splitting at every x-intercept and adding the absolute values.
  • Between two curves: ∫ (upper − lower) dx. Identify which is which with a test point inside the interval, and split wherever they cross.

If both curves are known at the limits, an exponential term can often be evaluated without touching an exponential: the antiderivative of A ekx is g (x)k, and g is given at both ends.

5.5 Average value of a function

avg = 1b − a ∫ab f (x) dx
Trap — two of them

This is not the mean of a random variable — no probability is involved. And the answer can be negative: for 4x3 − 3x4 on [0, 2] it is −85, because past x = 43 the area below the axis outweighs the area above.

5.6 The trapezium rule

A ≈ h2( y0 + 2y1 + … + 2yn−1 + yn )

n strips need n + 1 ordinates; every interior ordinate is counted twice.

Direction of the error follows concavity: concave up (f ″ > 0) ⇒ chords sit above the curve ⇒ the estimate is too large. Concave down ⇒ too small. The number of strips does not affect the direction.

Discrete and continuous random variables

Probability

6.1 Discrete random variables

A probability distribution is valid when every p(x) ≥ 0 and Σ p(x) = 1. That second condition is how an unknown in the table is found.

QuantityFormula
E(X) = μΣ x · p(x)
E(g(X))Σ g(x) · p(x)
Var(X) = σ2E(X2) − μ2 = Σ x2p(x) − μ2
sd(X) = σ√Var(X)

How it's asked: a table with one or two unknowns plus a stated mean. Two equations — the probabilities sum to 1, and Σ x p(x) equals the given mean — solve simultaneously.

6.2 Linear change of variable

E(aX + b) = a E(X) + b
Var(aX + b) = a2 Var(X)  ·  sd(aX + b) = |a| sd(X)
Trap

The + b shifts the mean but leaves the spread alone, and the a is squared in the variance but only in absolute value in the standard deviation. An option set will offer a Var(X), a Var(X) + b and a2Var(X) + b alongside the right answer.

These hold for continuous variables identically — nothing about them depends on the variable being discrete.

6.3 The binomial distribution

X ~ Bi(n, p) requires all four: a fixed number of trials, exactly two outcomes each, independent trials, and constant p. Sampling without replacement from a small population fails independence — that is the usual "which of these is not binomial" answer.

Pr(X = x) = nCx px(1 − p)n−x
E(X) = np  ·  Var(X) = np(1 − p)  ·  sd(X) = √np(1 − p)
PhraseCompute
at least one1 − Pr(X = 0)
at most kPr(X ≤ k)
more than k1 − Pr(X ≤ k)
fewer than kPr(X ≤ k − 1)
at least k1 − Pr(X ≤ k − 1)

How it's asked: find the smallest n for which the probability of at least one success exceeds 0.9. Set 1 − (1 − p)n > 0.9, solve for n with logarithms or CAS, then round up to the next integer — n is a count, so the ceiling is always the answer even when the solved value is 6.02.

Method — the mode of a binomial

Ask for the most likely number of successes and you want the x maximising Pr(X = x). Evaluate the two integers either side of np and compare; do not just round np.

6.4 Conditional probability

Pr(A | B) = Pr(A ∩ B)Pr(B)

A and B are independent exactly when Pr(A ∩ B) = Pr(A) Pr(B), equivalently Pr(A | B) = Pr(A). Mutually exclusive events with non-zero probability are never independent.

Trap — the intersection, not the numerator you were handed

For Pr(X < 4 | X ≥ 2) the numerator is Pr(2 ≤ X < 4), not Pr(X < 4). Write the intersection out as an explicit range before dividing. Note also that the complement of X < 4 given X ≥ 2 is X ≥ 4 given X ≥ 2 — the two conditional probabilities sum to 1, which is a fast check.

6.5 Continuous random variables — the pdf

f is a probability density function on [a, b] when both hold:

  • f (x) ≥ 0 for all real x (zero outside the support);
  • ∫ab f (x) dx = 1.
Pr(c ≤ X ≤ d) = ∫cd f (x) dx

Because a single point has zero area, Pr(X = c) = 0 and < may be swapped for ≤ freely. Never do that with a discrete variable.

6.6 Finding the constant

Integrate the density over its support, set the result to 1, solve. If the resulting equation is quadratic you will get two values — reject any that make f negative somewhere on the support, and reject any that fall outside a stated domain for the parameter.

Trap

Read the density exactly as printed. A squared factor, a squared whole density, or a support that is [0, a] rather than [0, 1] changes the integral completely, and the wrong reading almost always still produces a clean-looking constant.

6.7 Continuous measures of centre and spread

Mean and variance

μ = ∫ x f (x) dx
Var(X) = ∫ x2f (x) dx − μ2

Both integrals run over the whole support.

Median m

∫am f (x) dx = 12

Equivalently F(m) = 0.5. Percentiles work the same way with 0.5 replaced.

Mode

The x maximising f. Solve f ′(x) = 0 and also test the endpoints of the support — a density increasing throughout has its mode at the right endpoint.

6.8 The cumulative distribution function

F(x) = Pr(X ≤ x) = ∫ax f (t) dt

Written in full it is piecewise, and the outer branches are part of the answer:

F(x) = 0 for x < a; the integral for a ≤ x ≤ b; 1 for x > b.

Then Pr(c < X < d) = F(d) − F(c), and f (x) = F ′(x) — differentiating the cdf recovers the density, which is worth remembering when a question hands you F and asks for a mode or a mean.

The normal distribution

Normal

7.1 Shape and the empirical rule

X ~ N(μ, σ2) is symmetric about x = μ, where its mean, median and mode all sit. Total area 1, so each half is 0.5. Points of inflection at μ ± σ.

IntervalProbability
μ ± σ≈ 0.68
μ ± 2σ≈ 0.95
μ ± 3σ≈ 0.997

One tail beyond μ + 2σ is (1 − 0.95)/2 = 0.025. Halving is the step that gets dropped.

7.2 Standardisation

Z = X − μσ,  Z ~ N(0, 1)

A z-score is a count of standard deviations from the mean, sign included. It is the only way to compare values from two different normal distributions — a mark of 72 with z = 1.4 beats a mark of 80 with z = 0.9.

Trap — variance is not standard deviation

N(μ, σ2) names the variance in the second slot; every calculator and every formula wants σ. "Variance 9" means σ = 3. Distractors are always built from the un-square-rooted value.

7.3 Inverse normal — going from a probability back to a value

Given Pr(X < k) = p, the inverse normal returns k directly. Given a right tail Pr(X > k) = p, feed in 1 − p: technology works from the left tail unless told otherwise.

  • Sketch the curve and shade the region named. This single step prevents almost every inverse-normal error.
  • Convert the shading to a left-tail area.
  • Apply the inverse normal with μ and σ (not σ2).
  • Sanity-check the side: an area below 0.5 must return a value below μ.

How it's asked: find k such that 10% of components exceed k mm. The shaded region is the right 10%, so the left area is 0.9.

7.4 Recovering μ or σ

One unknown needs one probability statement; two unknowns need two.

  • Turn each probability into a z-value with the inverse standard normal.
  • Write z = (x − μ)/σ for each.
  • Solve the resulting linear system.

Keep the z-values unrounded through the algebra; rounding at 1.96 or 2.05 propagates badly into a two-equation solve.

7.5 Normal feeding a binomial

A very common Section B chain: a normal probability becomes the success probability of a binomial.

  • Compute p = Pr(X > c) from the normal model.
  • Carry full precision into Y ~ Bi(n, p).
  • Answer the binomial question and round only at the end.
Trap

Rounding p to two decimals before the binomial step routinely shifts the fourth decimal of the final answer past the tolerance the marking scheme allows.

7.6 Conditional and symmetric normal probabilities

Nothing new — Pr(X > b | X > a) = Pr(X > b) / Pr(X > a) for b > a, since the intersection is just X > b. Symmetry gives free equalities: Pr(X < μ − c) = Pr(X > μ + c), and if Pr(X < a) = Pr(X > b) then μ is the midpoint (a + b)/2. That midpoint fact turns a two-unknown problem into a one-unknown problem instantly.

Statistical inference

Inference

8.1 The three quantities, kept apart

SymbolIsStatus
ppopulation proportionfixed, unknown
P̂sample proportion, X / na random variable
p̂one observed value of ita number

Everything in this section follows from keeping these three straight. p never varies; P̂ is the thing with a distribution; p̂ is one draw from that distribution.

8.2 The distribution of P̂

E(P̂) = p  ·  sd(P̂) = √p(1 − p)n

P̂ is unbiased: on average it lands on p. Its spread shrinks with √n — to halve the standard deviation you need four times the sample.

Trap

Since X ~ Bi(n, p) has sd = √(np(1 − p)), dividing by n gives √(p(1 − p)/n) — the n ends up inside the root and downstairs. Option sets always carry the version with n outside.

8.3 The exact sampling distribution for small n

For a small sample, P̂ is discrete and every value is listed exactly: the possible values are 0, 1/n, 2/n, …, 1, and

Pr(P̂ = kn) = Pr(X = k) = nCk pk(1 − p)n−k

How it's asked: a sample of 4 is drawn from a population in which p = 0.3; find Pr(P̂ ≥ 0.5). Translate the proportion back to a count — P̂ ≥ 0.5 means X ≥ 2 — then answer it as an ordinary binomial. Do not reach for a normal approximation; n = 4 is nowhere near large enough, and the exam expects the exact value.

8.4 Confidence intervals for p

( p̂ − z √p̂(1 − p̂)n,  p̂ + z √p̂(1 − p̂)n )

Margin of error

M = z √p̂(1 − p̂)n

The interval width is 2M. Half the width, not the whole width, is the margin.

Sample size for a target M

n ≥ z2 p̂(1 − p̂)M2

Always round up. A worst case uses p̂ = 0.5, which maximises p̂(1 − p̂).

Note the estimate p̂ — not p — appears inside the root: the whole point is that p is unknown.

8.5 Interpreting a confidence interval

Trap — the interpretation mark

A 95% confidence interval does not mean "there is a 95% probability that p lies in this interval". p is a fixed number; it is either in this particular interval or it is not. The correct statement is about the procedure: if many samples of the same size were taken and an interval computed from each, about 95% of those intervals would contain p.

  • An interval containing a claimed value gives no evidence against that claim; an interval excluding it gives evidence against it.
  • Raising the confidence level widens the interval (z grows). Raising n narrows it.
  • Two different samples give two different intervals — that variation is the sampling distribution at work, not an error.

Trap — the value on exit

The loop stops when the condition first fails, so the counter's final value is one step past the last one that satisfied it. Asked "what is i when the loop ends", the answer is the failing value, not the last passing one.

9.3 The bisection method

Finds a root of a continuous f on [a, b] when f (a) and f (b) have opposite signs — that is, f (a) · f (b) < 0. Without a sign change the method cannot start.

  • Let m = (a + b)/2.
  • If f (a) · f (m) < 0 the root is in [a, m], so replace b with m; otherwise replace a with m.
  • Repeat until the interval is shorter than the required accuracy.
width after n steps = b − a2n

So the number of iterations needed for a tolerance ε comes from (b − a)/2n < ε. Bisection always converges, but slowly — one binary digit per pass.

A repeated even root (the curve touches the axis without crossing) has no sign change, so bisection misses it entirely. That is a standard multiple-choice distractor.

9.4 Newton's method

xn+1 = xn − f (xn)f ′(xn)

Geometrically: follow the tangent at xn down to the x-axis. It converges much faster than bisection when it converges at all.

Worked pass. For f (x) = sin(x) + 1 from x0 = 2π/3: f = 1.866, f ′ = −0.5, so x1 = 5.827; then f = 0.545, f ′ = 0.891, giving x2 ≈ 5.2. Note the first step throws the estimate a long way — a near-zero derivative does that.

Trap — when it fails
  • f ′(xn) = 0: the tangent is horizontal and the next term is undefined. A starting value at a stationary point breaks it immediately.
  • A small f ′ flings the iterate far away, often to a different root than the one intended.
  • It can cycle or diverge; unlike bisection there is no guarantee.

Questions are usually "perform two iterations, giving the answer to 2 decimal places" — keep every intermediate value at full calculator precision and round once, at the end.

9.5 Accumulation algorithms

Numerical integration appears as pseudocode: a running total A ← 0, a step h ← (b − a)/n, and a loop adding one contribution per pass.

Left rectangles

A ← A + h · f (x) then x ← x + h. Underestimates an increasing function.

Right rectangles

x ← x + h then A ← A + h · f (x). Overestimates an increasing function.

Trapezium

A ← A + h2( f (x) + f (x + h) ). Error direction set by concavity (§5.6).

The order of the two lines inside the loop is the whole difference between the left and right rules. Read the indentation carefully before deciding which one is on the page.

10.2 Exact values, rounding, and where marks leak

  • Exam 1 is always exact: π/6, √2, loge3, fractions — never a decimal, unless the question says otherwise.
  • Rationalise and simplify: an unsimplified surd or an uncancelled fraction can cost the final mark.
  • Round once, at the end. Store intermediate values in calculator memory rather than retyping rounded ones.
  • Follow the instruction exactly — "correct to 2 decimal places" and "correct to 2 significant figures" are different answers.
  • A probability rounded to 4 decimal places is the default when nothing is stated.
  • Give the thing asked for: a point needs both coordinates; a domain needs interval notation; a rule needs "y =" or "f (x) =".

10.4 Section A — twenty questions, sixty minutes of the paper

  • Roughly 1.5 minutes each. If a question passes three minutes, mark it and move on.
  • Substitute a test value rather than manipulating algebra: for transformations, inverses and composites, one well-chosen point eliminates three options at once.
  • Check the form of the options before solving — if they differ only in a sign or a factor of 2, find the step that decides that and do only that step.
  • Domain and range answers can be tested at the endpoints.
  • Never leave one blank. There is no penalty for a wrong answer.
  • Confirm the option count on the front of the paper: 2023 and the 2024 NHT paper used A–E; the recent papers use A–D.

10.5 Section B and Exam 1 — where the method marks are

  • Write the rule you are using before substituting; that line frequently carries a mark on its own.
  • A later part almost always depends on an earlier one. If you cannot get part (a), assume a plausible result, say so, and carry it forward — consequential marks are available.
  • Answer in the units and the variable the question uses.
  • Cross out rejected work rather than erasing it — anything not crossed out is marked, and a contradictory second answer can lose the mark you already earned.
  • Do not stop at the derivative when the question asks for a coordinate, a value of k, or an interval.
  • On Exam 2, quote the calculator's result to full precision in your working before rounding in the answer line.
Method — the thirty-second check before you move on

Does the answer have the right sign? The right units? Is it in the domain that was given? Is it the quantity asked for — a probability between 0 and 1, an integer where a count was wanted, both coordinates where a point was wanted? Four of the twenty-four traps above are caught by that check alone.
